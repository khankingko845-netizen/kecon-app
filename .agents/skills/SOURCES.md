# Nguồn skill

Tuyển chọn từ https://skills.sh (Open Agent Skills Ecosystem). Giữ nguyên nội dung gốc và giấy phép của từng repo.

|---|---|
| [mattpocock/skills](https://github.com/mattpocock/skills) | grill-me, grill-with-docs, to-spec, to-tickets, domain-modeling, research, codebase-design, improve-codebase-architecture, tdd, implement, diagnosing-bugs, code-review, prototype |
| [obra/superpowers](https://github.com/obra/superpowers) | brainstorming, writing-plans, subagent-driven-development, dispatching-parallel-agents, systematic-debugging, verification-before-completion, requesting-code-review |
| [anthropics/skills](https://github.com/anthropics/skills) | frontend-design, webapp-testing, doc-coauthoring, mcp-builder |

| [supabase/agent-skills](https://github.com/supabase/agent-skills) | supabase-postgres-best-practices |
| [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | ui-ux-pro-max, design-system |
| [leonxlnx/taste-skill](https://github.com/leonxlnx/taste-skill) | taste-skill |

Cập nhật: `npx skills add <owner/repo>` hoặc clone lại repo nguồn.

Lưu ý khi dùng trong dự án này: skill nhắc tới GitHub issue tracker → dùng GitHub Issues của repo hoặc Notion; skill nhắc tới lệnh slash của Claude → làm theo quy trình, bỏ qua cú pháp lệnh.
