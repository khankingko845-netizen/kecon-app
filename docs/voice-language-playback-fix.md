# Voice language and playback consistency

## Root causes
- Eleven Multilingual v2 does not support Vietnamese. A voice labelled Vietnamese is not enough: the synthesis model must also support it. Both synthesis entry points now use Flash v2.5 for Vietnamese when the configured model is incompatible, with explicit `language_code=vi`. Compatible v3/Turbo/Flash v2.5 is retained. Platform requests no longer take an arbitrary client model preference over admin settings; BYO remains permitted only by existing guards.
- Catalogue search previously searched only the first downloaded page. Name search now goes to the provider, with load-more pagination and cancellation. Exact IDs are checked directly across the key pool. Provider native language is displayed separately from verified additional languages; filters never invent a language from the request. Unknown and additional-language voices require opt-in in the picker.
- Selecting a new narrator could retain per-character voices and merge used a separate plain-text TTS path. All play/prefetch/merge now use the same segment plan. Default is one narrator for the whole story, including dialogue. Multi-character voices require explicit opt-in; picking a narrator resets that mode.
- Legacy `audio_url` had no identity. Migration 024 adds nullable `audio_key`: SHA-256 over text/voice segments, locale and effective model. Player only reuses exact matches; old files are retained, not assumed valid. This may require regenerating old audio (existing quota applies). Alternative audio is stored with its own identity, not mislabelled as original narration. Original uploaded audio files are NOT deleted by this migration. Player does not automatically play legacy uploaded audio whose identity is unknown.
- Scene matching used broad dialogue words and defaulted to loud synthetic layers. Background ambience now defaults off, has gentler volume/fades, ducks under narration, uses only scene descriptions/explicit supported ambience categories and remains quiet for ambiguous scenes. These are synthesized ambient effects, NOT new natural recordings or a quality benchmark.

## ID and provider account access
An ID alone is not guaranteed to resolve through ElevenLabs library name search. Private/deleted/unadded voices may return `voice_not_found`. Exact lookup reports account access honestly instead of picking a similar voice. To add by ID, first add the voice to My Voices on an ElevenLabs account whose key is in the pool. For library results containing public_owner_id, the explicit Add action imports on a pool account and binds/stores the RETURNED voice ID. No silent voice substitution. Import may use a provider voice slot; failures/tiers/permissions are shown. Manager import is audited. Default API validates provider availability and matching native/verified metadata, or requires explicit administrator confirmation of language.

Creation validates active owned family or active locale-curated voice before story quota/LLM, records server-provided narrator ID/name. Editor changes clear remembered playback overrides. Full story safety/approval, atomic persistence, quota refunds, consent/revocation and multi-version audio cache remain separate tickets.
